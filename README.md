<h1>🌤️ Weather App</h1>

A simple and responsive Weather App built with Vanilla JavaScript (for Learning purposes) and the OpenWeather API.
This app allows users to search for any city and instantly get the current weather conditions including temperature, weather description, and forecast up to 5 days.

<h2>🚀 Features</h2>

🔍 Search weather by city name

🌡️ Real-time temperature (°C)

☁️ Weather condition icons (Clear, Clouds, Rain, etc.)

📅 Forecast support for 5 days

🎨 Simple and responsive UI

<h2>🛠️ Tech Stack</h2>

HTML5

CSS3

JavaScript (Vanilla JS)

OpenWeather API
